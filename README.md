# 尚順國際運通一頁式網站

## 使用方式

1. 解壓縮 ZIP
2. 將公司 LOGO 放到 `public/logo.png`
3. 將 LINE QR Code 圖片放到 `public/line-code.png`
4. 在專案資料夾開啟終端機，執行：

```bash
npm install
npm run dev
```

## 圖片檔名

- LOGO：`public/logo.png`
- LINE QR Code：`public/line-code.png`

## 主要檔案

- `src/App.jsx`：網站主頁面
- `src/index.css`：Tailwind 與全站樣式
- `tailwind.config.js`：Tailwind 設定
