# 尚順國際運通有限公司官網專案

此版本已調整為企業形象官網風格，架構接近正式物流公司網站：

- 首頁大圖 Hero
- 公司簡介
- 服務項目
- 物流流程
- 網購集運回台
- 常見問題
- 線上詢價 Google 表單
- LINE QR Code 與 Google 地圖

## 使用方式

```bash
npm install
npm run dev
```

## 圖片檔請放在 public 資料夾

請放入以下檔案名稱：

- `logo.png`：尚順公司 LOGO
- `line-qr.png`：官方 LINE QR Code
- `global-logistics.png`：首頁背景圖
- `about-logistics.png`：首頁右側物流形象圖

如果已經有原本專案的 public 資料夾，直接覆蓋 `src/App.jsx`、`src/index.css`、`package.json` 即可。
