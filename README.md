# 尚順國際運通 Vite 官網專案

## 上傳位置

- `src/App.jsx`
- `src/main.jsx`
- `src/index.css`
- `index.html`
- `package.json`

## 圖片放置位置

請把以下圖片放進 `public/`：

- `logo.png`：公司 LOGO
- `line-qr.png`：LINE QR Code 圖片
- `hero-bg.png`：首頁與分頁共用背景圖
- `global-logistics.png`：首頁右側物流路線整合圖

## 本機啟動

```bash
npm install
npm run dev
```

## Vercel 部署

Build Command:

```bash
npm run build
```

Output Directory:

```bash
dist
```
